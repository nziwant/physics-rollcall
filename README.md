# 唐高祖讲物理 · 课堂点名助手 V1.16

## 版本定位
V1.16 是名单排序优化版：学生名单、课堂签到、作业检查、补录出勤、历史记录中的姓名显示，按中文拼音顺序排序，便于老师快速辨识和查找。

## 电脑测试方法
1. 解压文件夹。
2. 双击 `index.html` 即可在电脑浏览器中打开。
3. 先新建班级，再进入班级导入学生名单。
4. 上课前点击“课堂签到”，把未到学生切换为“未出勤”。
5. 上课中点击“智能点卿”。

注意：双击本地文件可以测试功能，但 PWA 离线缓存和添加到主屏幕的完整体验，需要部署到 HTTPS 网址后使用。

## iPad 使用方法
1. 把整个文件夹部署到 GitHub Pages / Vercel / Cloudflare Pages 等静态网站服务。
2. 用 iPad 的 Safari 打开部署后的网址。
3. 点 Safari 的分享按钮。
4. 选择“添加到主屏幕”。
5. 以后从 iPad 桌面图标打开。

## 重要提醒
所有班级、学生、签到、点卿记录都保存在当前浏览器本地。换设备、清理浏览器缓存、升级版本前，请先在“设置”里点击“一键备份全部数据”。


## iPad 音效说明

iPad Safari 和主屏幕网页 App 会限制网页自动播放声音。第一次使用时，请在班级页面点击“开启音效”，听到提示音后再使用“智能点卿”。

如果仍然没有声音，请检查：
1. iPad 音量是否调大；
2. 是否处于静音/专注模式；
3. 软件设置中的音效是否开启；
4. 是否从主屏幕重新打开过一次新版。
