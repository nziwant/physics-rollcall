# 唐高祖讲物理 · 课堂点名助手 V1.4

## 版本定位
V1.4 是 iPad 主力使用版，重点优化：添加到主屏幕、离线缓存、iPad 横屏体验、数据备份恢复。

## 电脑测试方法
1. 解压文件夹。
2. 双击 `index.html` 即可在电脑浏览器中打开。
3. 先新建班级，再进入班级导入学生名单。
4. 上课前点击“课堂签到”，把未到学生切换为“未出勤”。
5. 上课中点击“智能点卿”。

注意：双击本地文件可以测试功能，但 PWA 离线缓存和添加到主屏幕的完整体验，需要部署到 HTTPS 网址后使用。

## iPad 使用方法
1. 把整个文件夹部署到 GitHub Pages / Vercel / Cloudflare Pages 等静态网站服务。
2. 用 iPad 的 Safari 打开部署后的网址。
3. 点 Safari 的分享按钮。
4. 选择“添加到主屏幕”。
5. 以后从 iPad 桌面图标打开。

## V1.4 新增 / 优化
- 新增 PWA 配置：`manifest.webmanifest`。
- 新增离线缓存：`service-worker.js`。
- 新增专属图标：`icons/icon-192.png`、`icons/icon-512.png`。
- 优化 iPad 横屏、触控按钮、安全区域适配。
- 首页加入 iPad 添加到主屏幕提示。
- 设置页加入“iPad 主屏幕安装”说明。
- 数据备份 / 恢复改为更醒目的“一键备份全部数据”和“选择备份文件恢复”。
- 保留高级 JSON 复制 / 粘贴恢复。

## 已有功能
- 班级管理。
- 学生管理与批量导入。
- 课堂签到。
- 智能点卿：科技动画 + 随机 + 去重。
- 重新抽取。
- 本轮统计。
- 历史签到记录查询。
- 签到表 CSV 导出。
- 课堂点卿记录查询。
- 课堂记录 CSV 导出。
- 投屏模式。
- JSON 备份与恢复。

## 重要提醒
所有班级、学生、签到、点卿记录都保存在当前浏览器本地。换设备、清理浏览器缓存、升级版本前，请先在“设置”里点击“一键备份全部数据”。
